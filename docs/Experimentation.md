# Exploratory Data Analysis

Firstly, our dataset is composed of 114,000 observations and 21 variables. This dataset consists of 114,000 Spotify tracks across 125 genres. Our set of variables are devided into 3 parts. The first part contains the identifier variables such as the track_id, artists, album_name, track_name and track_genre. Then, the second part is related to the target variable, popularity (integer, between 1 and 100), calculated by Spotify's algorithm based on total plays and recency. Further, before the training step, the variable will be transformed into a binary variable called hit between 0 (flop) and 1 (hit) where the threshold is set to popularity >= 65. We con observe that our dataset is made up of 9477 hits (8.31%). Then, the third group of variables which are the exploratory variables are composed of some audio features such as danceability, tempo, duration_ms and so on. 

Afterwards, we can notice that our dataset is composed of just one observation over all our dataset which contain a missing value for artists, album_name and track_name, which is not disturbing because those are related to identifiers. 

Then, by analyzing the correlation pot our variables, we can notice that most of the variables are not very correlated because the two extreme correlation coefficient are 0.76 and -0.73, and the others coefficient are low positive/negative correlation coefficient. This suggests that most features contains different information. Moreover, by performing a PCA with 2 and 3 PC without the identifiers and the non categorical features, we can observe that the three first PC explain a small part of the variance respectivement 0.28, 0.15 and 0.12. This suggests that the data cannot be well summarized into 2 or 3 components meaning that the information is spread across many features as noticed before.

# ML model

In order to implement our ML model, we have decided to train 3 algorithms and evaluate them : gradien boosting (see gb.py), k nearest neighbors (see knn.py) and random forest (rf.py). For the three models, we have decided to split the dataset into 2 parts a training set (70% of the original dataset) and a test set (30% of the original dataset). Moreover, this split is stratified meaning that the proportion of hit and flop is kept among the training and test set.# Stratify=y so that the proportion of 92% flops and 8% hits are kept in the train and test set. The training set will be used to train the models with different values for the corresponding hyperamaters of each algorithm such as the `n_neighbors` in knn, `n_estimators` and `max_depth` in random forest and `learning_rate`, `n_estimators` and `max_depth` in gradient boosting. Those training on the training set are evaluated by using the cross-validation to determine the best values of the hyperparameters for the algorithm. This cross-validation is perfomed by the `StratifiedKFold` in order to keep the same class proportion in each fold due to the imbalance class proportion of our input. In addition, we have also set the `shuffle` argument to `True` in order to shuffle the folds. The evaluation criterion choice is the f1 score because the f1 score is an harmonic mean between the precision and recall so that it penalizes extreme imbalance contrary to just looking at the accuracy, recall or precision. Afterwards, the model is trained on the training set with the best hyperparameters values and it is finally tested on the test set to be compared with the other models.

Firstly, in the case of the knn, we have decided to use `KNeighborsClassifier` function by setting the `weights` argument equals to `distance` in order to give more influence to the closer neighbors. Moreover, we have also decided to scale the inputs before applying the algorithm because in our dataset, features are on different scales such as ms, DB and normalized values between 0 and 1. Then, the best `n_neighbors` is equal to 2000 with a test f1 equals to 0.67.

In the case of random forest, due to the unbalanced output (8.31% of hits), we have set the argument `class_weight` of `RandomForestClassifier` at `balanced` so that the algorithm will increase the importance of the underpresented class during the training i.e. the hit class. The best hyperparameters are : `bestN_estimators` equals to 100 and `max_depth` equals to `None` with a test f1 equals 0.65. 

In the case of gradient boosting, the best hyparametrs are : `learning_rate` equals to 500, `n_estimators` equals to 5 and `max_depth` equals to 0.2 with a test f1 equals to 0.39.

Finally, the best model is knn with `n_neighbors` equals to 2000.
